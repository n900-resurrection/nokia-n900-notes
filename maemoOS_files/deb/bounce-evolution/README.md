# Bounce Evolution (Nokia N900)

A backup copy of the package of **Bounce Evolution**, the 3D technology demo that Rovio Mobile made for the Nokia N900 in 2009 (published by Nokia), in case the mirrors that host it disappear.
The game belongs to Rovio and Nokia; this copy is kept as an archive.

Install on the phone (copy to `/home/user/`, as root): `dpkg -i bounce_1.0.1_armel.deb`. Check the file first: `sha256sum -c SHA256SUMS`.
